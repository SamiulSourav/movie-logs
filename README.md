# Movie Logs

Track the movies you want to see and the ones you've watched, rate and take notes on them, and get suggestions for what to watch next.

| Folder | What it is |
|---|---|
| [web/](web/) | Vue 3 + Vite frontend. Runs on sample data until the server exists. See [web/README.md](web/README.md). |

The API server will live in `server/`.
